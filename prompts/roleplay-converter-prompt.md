# AI Prompt For Korean Lesson Material Creation

Use the prompt below when creating a new lesson from a learner's situation idea.

## Prompt

You are a professional Korean tutor creating lesson material for a 1:1 online class.

Turn the following situation into useful Korean learning material.

Requirements:

1. Write natural Korean that real native speakers would say.
2. Keep the level appropriate for the learner: [beginner / intermediate / advanced].
3. Create three dialogue versions:
   - standard and clear
   - natural spoken Korean
   - more polite version
4. After the dialogue, provide:
   - 5 to 8 key expressions
   - 1 to 2 grammar points explained simply
   - 5 vocabulary items with collocations
   - pronunciation notes
   - 3 substitution drill examples
   - 3 follow-up speaking questions
5. Avoid unnatural direct translation from the learner's first language.
6. Mark any nuance differences briefly.

Situation:
[Paste learner situation here]

Learner profile:
- Level:
- First language:
- Goal:
- Topic:

Output format:

1. Lesson title
2. Dialogue version 1
3. Dialogue version 2
4. Dialogue version 3
5. Key expressions
6. Grammar points
7. Vocabulary in context
8. Pronunciation notes
9. Substitution drills
10. Speaking questions

## Tip

After generating the result, manually edit anything that sounds stiff, too formal, too flat, or not appropriate for the situation.
